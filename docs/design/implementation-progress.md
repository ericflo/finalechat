# Implementation and validation record

Status: implemented, validated and committed locally. September 8, 2026. The production deployment and existing user services have not been changed.

The implementation replaces the proposed localhost proxy with durable session websites and an independently paired settings command channel. See [setup and operating details](../integrations.md), [artifact design](session-artifacts.md), [interactive settings design](interactive-settings.md), and [the API reference](../API.md).

## Delivered behavior

- FinaleChat stores immutable manifests and content-addressed chunks through its existing private B2 abstraction. Upload/commit, historical revisions, quota enforcement, deletion/cleanup, original file downloads and ZIP downloads have their own artifact lifecycle. Proactive publishers retain pending capture identities and recover lost acknowledgements. Competing parents require a new capture preserving published native prefixes; deletion pauses publication until explicit recreation.
- The thread's artifact container opens portable websites in opaque sandboxed iframes. The scoped SDK supplies only the selected revision's files and approved presentation/settings operations. No account or connector token enters the iframe. Extracted websites work offline and verify file hashes. Explicit viewer replacement preserves all original data and context; following new data pauses when the renderer or dataset identity changes.
- Eagent exports original committed JSONL, tool outputs, attachment completeness, frozen pricing and labeled configuration/runtime context. Its portable Go/WASM replay uses the actual reducer and shared projections. Claude Code and Codex retain native transcript/rollout bytes, including discovered subagents where supported. Verified restore writes original source files into a fresh directory without executing agents or external effects.
- Chat messages and native records can link in both directions using bounded dataset/session anchors. Native Codex MCP call metadata selects the same thread as its archive; explicit thread choices remain authoritative. The viewers report missing events and display limits rather than implying that a loaded prefix is the whole archive.
- Settings pairing grants exact resources, scopes, operations and capability classes. A trusted FinaleChat Save/action submits reviewed typed commands, with owner checks, expected versions, fenced renewable leases, local revalidation, durable intent/results and append-only audit. Historical documents do not acquire editing authority. A current editor can retain its bounded editing lease across transcript publications; revocation, deletion or generation changes end authorization.
- Eagent embeds its actual local configuration editor and stylesheet, covering routes/models/fallbacks, prompt overrides, named configurations, default selection, scheduling and mirror/archive preferences. Conditional undo uses private journal evidence and fresh version/grant checks. Saved-route tests require a separate reviewed action. Shared locks and atomic writers serialize cooperating local and remote changes.
- Separately paired eagent session resources expose task concurrency and narrator check/quiet timing through the real scheduler. Native events precede success acknowledgements. Reducing concurrency preserves active workers; narrator timer generations fence old callbacks. Expired commands and uncertain outcomes are not blindly replayed, and resume starts a fresh generation with project defaults.
- Claude Code's existing hooks and MCP integration now include portable export, proactive capture and scoped user/project/project-local settings. Codex uses supported native read/config APIs, a standalone companion and conditional user-config writes. Installation preserves unrelated hooks, servers, settings and existing tool approval policy. The distributed CLI remains one Python 3.9+ file using only the standard library.

## Deliberate limits

- Nothing has been pushed or deployed, and uploading remains opt-in. Durable artifacts preserve the latest successfully published revision; a machine lost before its next successful upload can lose that unpublished tail. Detached companions are not boot services; an OS supervisor can keep their foreground command running.
- Claude Code and Codex settings saves describe persistent defaults, not a confirmed live model/effort switch in another process. Native policy remains authoritative. Codex's writable scope is user defaults; direct project/profile writes and ownership of another desktop/terminal session are not advertised. Credentials, executable helpers and unsupported values are excluded or identified without rewriting unknown native keys.
- Eagent's live controls apply only to the acknowledged process generation. Other settings apply to new/resumed sessions. `EAGENT_FINALECHAT=off` gates every outbound integration path, including final publication and stored session connectors. Local export works with invalid project defaults; network publication waits for a valid configuration to determine opt-in and destination.
- Captured defaults are observations at capture time. Historical configuration, pricing/invoice facts and external effects that were never recorded cannot be reconstructed as known facts. Viewers display bounded prefixes with complete saved sources downloadable separately. Restore does not replay tool side effects or reconnect stale process identities.
