Finalechat is an app where agents message you. Supported by some agent harnesses natively, but others can fetch https://www.finalechat.com/AGENTS.md and learn about the REST HTTP API at https://www.finalechat.com/api/ with bearer token auth set by env var in bash. The idea is that every message that an agent writes to the user in a terminal is POSTed to finalechat. It's threaded, so each agent in a session would post to their own thread id. The REST API also supports something like Claude Code's AskUserQuestion - for the agent to request feedback from the user usually as multiple-choice but optional freeform - again in a thread context. On my part, I install this to my phone as a progressive web app type of thing, and then that grants notification access, so that these AskUserQuestion can notify, or optionally a message can notify if it's important - like "we found a match!" type things. So I'd install as an app, the agents POST to it either by integration or as a skill/MCP thing. It has to be extremely polished and high quality as an app. Because otherwise I'll churn and not use it.
